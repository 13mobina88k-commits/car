# Ultimate Racing | آلتیمیت ریسینگ

بازی مسابقهٔ اتومبیل‌رانی **حرفه‌ای و کاملاً آفلاین** در قالب **یک فایل مستقل HTML** — بدون نیاز به نصب، سرور یا اینترنت.

## نحوهٔ اجرا

کافیست فایل [`UltimateRacing.html`](UltimateRacing.html) را با هر مرورگری (Chrome، Firefox، Edge، Safari) باز کنید. همین!

## امکانات

- **۸ خودروی مسابقه‌ای** با ظاهر و مشخصات متفاوت (سرعت، شتاب، هندلینگ، ترمز) + نمایش امتیاز کلی
- **۳ مسیر کاملاً متفاوت**: خیابان‌های شهر (شب‌نشینی نئونی)، گردنهٔ دماوند (پیچ‌های کوهستان)، کویر لوت (سرعت نهایی روی آسفالت داغ)
- **۵ رقیب هوش مصنوعی** با رفتار طبیعی: ترمز در پیچ‌ها، سبقت، مانع‌یابی، رانندگی تهاجمی یا محافظه‌کارانه
- **۳ سطح سختی** (آسان / متوسط / سخت) و **۱ تا ۵ دور** مسابقه
- رندر **شبه‌سه‌بعدی** با HTML5 Canvas: پرسپکتیو جاده، کوه‌ها، ساختمان‌های چراغ‌دار، کاکتوس و کاج، دروازهٔ استارت، خط شطرنجی شروع/پایان
- **نقشهٔ کوچک مسیر** (Mini-map) + **نوار پیشرفت** با نقطهٔ خودروها
- HUD کامل: کیلومترشمار، رتبه، شمارندهٔ دور، زمان مسابقه، بهترین دور
- **صداهای Web Audio**: موتور، گاز، ترمز، برخورد، سبقت، شمارش معکوس، پایان مسابقه — با قابلیت قطع/وصل
- کنترل لمسی کامل موبایل (گاز/ترمز/فرمان) + کیبورد (W/S/A/D یا جهت‌دارها، Space ترمز دستی، P مکث)
- تنظیمات گرافیک (کم/متوسط/عالی)، ثبت **رکورد بهترین زمان** برای هر مسیر و تعداد دور (localStorage)
- تمام منوها فارسی و راست‌چین، طراحی تمام‌صفحه و واکنش‌گرا (Responsive)

## ساختار

فقط یک فایل: `UltimateRacing.html` — شامل HTML + CSS + JavaScript خالص (بدون هیچ کتابخانهٔ خارجی).

## تست‌شده

بوت بدون خطا، انتخاب هر ۸ خودرو و ۳ مسیر، شروع/مکث/ادامه/شروع مجدد مسابقه، پایان مسابقه و ثبت رکورد، پایداری روی هر سه مسیر — با هارنس jsdom و موتور بوم واقعی (بدون مرورگر).
